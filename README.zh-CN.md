# dsh-memory-dba：功能范围

[English README](README.md) · 版本 0.1.4

本包是 DBA（Dual-Brain Architecture，双脑架构）的**文件记忆与检索插件**，不是完整双脑运行时。安装它不会同时安装 RWKV 小脑、连续状态后端或原 Python DBA 的可靠事件处理链。

0.1.2–0.1.4 是说明文档修订版：明确交付范围和限制、修正发布历史与一处写反的研究结论，没有新增运行时功能，也没有修复下列尚未实现的能力。

## 本 npm 包已实现

| 能力 | 实际行为 |
| --- | --- |
| 三层文件记忆 | core.md、stream.md、ws/*.md；可直接阅读和迁移 |
| 两段提示词注入 | 核心记忆与本轮召回分开；默认预算分别为 15 KiB 和 6 KiB |
| BM25 关键词检索 | 支持中英文混合、中文单字和双字；预算溢出时可按时间重排 |
| 可选语义召回 | 使用 Ollama/bge-m3 与手动建立的向量缓存；超过阈值的语义结果追加到关键词结果之后 |
| DSH 会话接入 | 监听用户/助手消息，在轮次结束时追加记忆流 |
| 当前记忆流写法 | 用户文本最多 300 字符、助手文本最多 600 字符，折成一行并做启发式脱敏；不是小模型提炼出的摘要 |

## 原 Python DBA 已有，但本包尚未迁入

| 能力 | 本包现状 |
| --- | --- |
| RWKV-7 会话连续状态、恢复与摘要后端 | 未接入 |
| 完整双方事件档案、独立事件向量召回 | 未接入；截断流水不能代替完整事件档案 |
| 持久 outbox、幂等收据与失败重试 | 未接入；当前 pending 只在内存中 |
| 消息草稿与中断轮次恢复 | 未接入 |
| core/ws 受控写入接口 | 未迁入；CLI write 只写 stream，core/ws 依赖普通文件操作 |
| 原系统的关键词、记事本向量与事件向量维护链 | 未完整迁入；本包语义缓存须手动执行 index |

这些能力在原 Python 系统中有实现，不能把它们写成“原 DBA 从未实现”，也不能把安装本包说成已获得这些能力。两个系统可并存，但共享同一记忆目录时没有并发写入协调，应只保留一个写入者。

## 整体 DBA 仍在研究、未达验收标准

- **RWKV 状态可靠解码为槽位或记忆码**：做过基于冻结 RWKV 特征的解码器训练实验。v4 完成 5000 步，验证集 1779 例里全槽精确命中 0/1779、内容槽准确率 1.6%，未通过验收，也未进入最终测试。但状态本身不是没用：真实状态 token loss 1.185 优于无状态 1.575、错配状态 1.260，同一池化特征上的逐标签线性探针 AUC 达 0.98 —— 信息在，失败的是联合多标签解码。这不等于 RWKV 主干微调已成功或已有可用状态接口。
- **跨模型状态消费**：云端目前消费文本摘要与检索原文，不是直接接收 RWKV 状态张量或专用记忆码。
- **经验证的模型常驻服务**：跨轮状态连续与进程/权重始终常驻是两回事，原系统也没有完成常驻部署验收。

旧五层架构的定期 consolidation/retire/dedupe 已列为 legacy，不属于当前三层架构已交付能力。

## 当前限制

1. **同进程并发会话不隔离**：latestHits 是共享槽，后一次查询会覆盖前一次的召回。隔离的回调级测试已复现；这不是完整 DSH 多会话端到端测试。本版未修复，可用独立进程隔离查询。
2. **旧流水可能搜不到**：仅最近 1000 条、合计最多 128 KiB 的非空流水记录进入检索；更旧的内容仍在文件里，却不在候选集中。1000 条窗口有隔离测试依据；128 KiB 上限来自源码，未单独进行端到端边界测试。长期细节应放入 ws。
3. **截断不等于理解或压缩**：用户/助手文本尾部可能丢失；核心记忆超预算时裁切注入内容，不会自动整理或压缩磁盘文件。
4. **语义缓存不会自动更新**：编辑记忆后需执行 index。未建立缓存、模型不可用或超时，会降级为 BM25；运行时不会主动提示所有降级原因，可用 doctor 检查缓存。
5. **写失败无可靠重试**：只记录错误日志，没有持久队列保证重试。脱敏是启发式规则，也不能保证移除所有秘密。
6. **默认目录与旧 DBA 不同**：Windows 默认 `%LOCALAPPDATA%/dsh-memory-dba`，其他平台默认 `~/.dsh-memory-dba`。要复用原库，须明确设置 home；仅安装插件不会自动找到旧 Python 仓库。

## 安装与配置

安装到实际运行的 DSH profile 目录，再在其 cordis.patch.yml 中添加：

```yaml
- insert:
    - id: memory-dba
      name: dsh-memory-dba
      config:
        home: '/absolute/path/to/existing/memory'
```

完整安装步骤、配置字段、向量索引与 CLI 用法见 [English README](README.md)。新增插件后需重启宿主。本轮发布不会替换用户已运行的插件或移动既有记忆。
